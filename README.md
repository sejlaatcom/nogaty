# نظام الأرشفة الإلكترونية للمدارس

نظام متكامل لحفظ الوثائق والملفات المدرسية وأرشفتها إلكترونياً وتسهيل الوصول إليها ومشاركتها
بين المستخدمين، مبني بلغة **PHP** وقاعدة بيانات **MySQL**، بواجهة عربية كاملة من اليمين لليسار.

---

## المزايا الرئيسية

### 🌳 شجرة أرشفة بمستويات غير محدودة
- بناء شجرة مجلدات هرمية بأي عدد من المستويات (مدرسة ← قسم ← عام دراسي ← تصنيف ← ملف).
- ربط كل مجلد بإدارة من الهيكل التنظيمي، مع رمز ولون ووصف وترتيب عرض.
- منع نقل المجلد إلى داخل أحد فروعه، ومنع حذف المجلدات التي بها محتوى.
- شجرة تفاعلية قابلة للطي مع حفظ حالة الطي في المتصفح.
- شجرة أرشفة افتراضية جاهزة تُنشأ عند التنصيب (٢٠ مجلداً).

### 🏫 الهيكل التنظيمي للمدرسة
- شجرة إدارات وأقسام بمستويات غير محدودة، مع تحديد مدير لكل إدارة.
- هيكل افتراضي جاهز: إدارة المدرسة، الشؤون التعليمية، شؤون الطلاب،
  الشؤون الإدارية والمالية، السكرتارية والصادر والوارد، وغيرها (١٥ إدارة).
- ربط المستخدمين والمعاملات والمجلدات بالإدارات.

### 📩 أرشفة المعاملات الخارجية والداخلية (الصادر والوارد)
- ثلاثة أنواع: **وارد** و **صادر** و **مذكرات داخلية**.
- ترقيم تلقائي آمن لكل نوع مع تسلسل مستقل يبدأ من جديد كل سنة،
  بصيغة قابلة للتخصيص: `{TYPE}-{YEAR}-{SEQ}` مثل `و-2026-00001`.
- تاريخ **هجري وميلادي** معاً، مع تحويل تلقائي عند الحفظ.
- الجهة المراسلة، من إدارة / إلى إدارة، التصنيف، العام الدراسي، مجلد الأرشفة.
- درجة الأهمية (عادي / عاجل / عاجل جداً) ودرجة السرية (عادي / سري / سري للغاية).
- حالة المعاملة (مسودة، مقيدة، قيد الإجراء، منجزة، مؤرشفة، مغلقة).
- تاريخ استحقاق مع تمييز المعاملات المتأخرة تلقائياً.
- ربط الصادر بالوارد الخاص به، كلمات مفتاحية ووسوم للبحث.
- سلة محذوفات مع استرجاع أو حذف نهائي.
- طباعة نموذج المعاملة مع **باركود Code128** لرقم القيد.
- تصدير المعاملات إلى **Excel/CSV** بترميز يدعم العربية.

### ➡️ الإحالة والتحويل بين الموظفين
- إحالة المعاملة لموظف واحد أو عدة موظفين، أو لكل موظفي إدارة دفعة واحدة.
- أنواع الإحالة: للإجراء اللازم، للعلم، للمراجعة، للاعتماد، للتوقيع، للحفظ.
- التأشيرة والتعليمات وموعد الإنجاز.
- ردّ المحال إليه (تم الإنجاز / تم الاطلاع / إعادة للمحيل) مع ملاحظات.
- تحديث حالة المعاملة تلقائياً إلى «منجزة» عند إنجاز كل الإحالات.
- إشعار فوري داخل النظام للمحال إليه وللمحيل عند الرد.
- صندوق «الوارد إليّ» لمتابعة ما يخص كل موظف.
- خط زمني كامل لسجل الإحالات على كل معاملة.

### 📎 المرفقات — ملفات Office وPDF ووسائط الفيديو والصوت
- رفع ملفات متعددة مع وصف لكل ملف.
- دعم صيغ **Office** (Word, Excel, PowerPoint) و**PDF** والنصوص،
  و**الصور** و**الفيديو** و**الصوت** والملفات المضغوطة.
- تخزين الملفات **خارج مجلد الويب** مع أسماء عشوائية — لا يمكن الوصول إليها إلا عبر النظام.
- بث الفيديو والصوت بدعم `Range` (تشغيل مباشر وتقديم/تأخير داخل المتصفح).
- عارض مدمج للصور والفيديو والصوت وملفات PDF.
- مكتبة مرفقات موحّدة مع تصفية حسب نوع الوسائط والمصدر.
- بصمة SHA-256 لكل ملف وعدّاد تحميلات.

### ☁️ دعم روابط قوقل درايف للعرض والتحميل
مصمّم للملفات الكبيرة (الفيديو والصوت والأرشيفات) دون استهلاك مساحة الخادم:

- ألصق أي رابط مشاركة من قوقل درايف، ويستخرج النظام معرّف الملف تلقائياً.
- يدعم كل صيغ الروابط: `/file/d/ID/view`، `?id=ID`، `/folders/ID`،
  ومستندات وجداول وعروض جوجل.
- يولّد النظام تلقائياً:
  - **رابط العرض** داخل إطار مدمج في صفحة المعاملة أو الوثيقة.
  - **رابط التحميل المباشر** (`uc?export=download`).
  - **رابط التصدير** لمستندات جوجل (PDF / XLSX / PPTX).
  - **صورة مصغّرة** للصور.
  - رابط الفتح في درايف.

> يجب ضبط مشاركة الملف في درايف على «أي شخص لديه الرابط — مُشاهد».

### 📄 الوثائق العامة
أرشفة الوثائق غير المرتبطة بمعاملة: اللوائح، التعاميم، محاضر الاجتماعات،
ملفات الطلاب، كشوف الدرجات، ملفات الموظفين — داخل شجرة الأرشفة مع مرفقاتها.

### 🔗 المشاركة بين المستخدمين
- روابط مشاركة برموز عشوائية طويلة لمشاركة معاملة أو وثيقة مع مرفقاتها.
- مدة صلاحية محددة، وحماية اختيارية بكلمة مرور.
- التحكم في السماح بالتحميل من عدمه، مع عدّاد مشاهدات وإمكانية الإلغاء الفوري.
- المستلم يطّلع دون حاجة لحساب في النظام.

### 🔎 البحث والوصول السريع
- بحث شامل فوري في المعاملات والوثائق والمرفقات معاً.
- اقتراحات فورية أثناء الكتابة في شريط البحث العلوي.
- بحث متقدم بمعايير متعددة: النوع، الحالة، الأهمية، السرية، الجهة، الإدارة،
  المجلد (شاملاً فروعه)، التصنيف، العام الدراسي، المدى الزمني،
  المتأخرة فقط، التي لها مرفقات فقط.
- فهارس `FULLTEXT` على المواضيع والنصوص والكلمات المفتاحية.

### 🔐 الصلاحيات والأمان
- نظام أدوار وصلاحيات دقيق (**٢٥ صلاحية** في ٧ مجموعات).
- ستة أدوار جاهزة: مدير النظام، مدير المدرسة، وكيل المدرسة،
  مسؤول الأرشفة، موظف، مطلع — وإمكانية إنشاء أدوار مخصصة.
- تقييد الموظف على المعاملات التي أدخلها أو أُحيلت إليه فقط.
- كلمات مرور مجزأة بـ bcrypt، وحماية CSRF على كل النماذج،
  وتقييد محاولات الدخول الفاشلة مع إيقاف مؤقت.
- منع رفع الملفات التنفيذية، والتحقق من المسارات لمنع الوصول لملفات خارج مجلد التخزين.
- تهريب كامل للمخرجات لمنع XSS، واستعلامات مُهيّأة لمنع حقن SQL.
- **سجل أحداث** شامل لكل عملية (دخول، إضافة، تعديل، حذف، اطلاع، تحميل، مشاركة، إحالة، طباعة).

### 📊 التقارير ولوحة المعلومات
- لوحة معلومات بإحصاءات حية ورسوم بيانية للحركة الشهرية والتوزيع بالتصنيف.
- تقارير: الحركة الشهرية، الأكثر مراسلة، الأكثر نشاطاً بالإدارات، التوزيع بالتصنيف
  والحالة والمستخدم، أكثر المجلدات محتوى، إحصاء المرفقات وأحجامها،
  والمعاملات المتأخرة عن مواعيدها.
- تقرير حركة معاملات جاهز للطباعة مع خانات التوقيع.

## متطلبات التشغيل

| المتطلب | الحد الأدنى |
|---|---|
| PHP | 8.0 فأحدث |
| MySQL / MariaDB | 5.7 / 10.3 فأحدث |
| إضافات PHP | `pdo_mysql`, `mbstring`, `fileinfo`, `json` |
| خادم الويب | Apache أو Nginx (أو خادم PHP المدمج للتجربة) |

لا يحتاج النظام إلى Composer أو أي مكتبات خارجية.

## التنصيب

### ١. رفع الملفات
ارفع محتويات المشروع إلى خادمك، ثم اضبط الصلاحيات:

```bash
chmod -R 775 storage app
```

### ٢. تشغيل برنامج التنصيب
افتح في المتصفح:

```
https://your-domain.com/install/index.php
```

يقوم البرنامج بـ:
1. فحص متطلبات التشغيل وصلاحيات المجلدات.
2. اختبار الاتصال بقاعدة البيانات وإنشائها إن لزم.
3. إنشاء الجداول وتعبئة البيانات الأولية (الأدوار، الصلاحيات، الهيكل التنظيمي،
   شجرة الأرشفة، التصنيفات، الجهات).
4. إنشاء حساب مدير النظام وضبط بيانات المدرسة.
5. توليد ملف `app/config.php` تلقائياً.

### ٣. بعد التنصيب — خطوات إلزامية

```bash
rm -rf install/
```

واجعل مجلد `public` هو جذر الموقع (Document Root):

```apache
DocumentRoot /var/www/school-archive/public
```

إن لم يمكنك تغيير جذر الموقع، فملف `.htaccess` في الجذر يحوّل الطلبات إلى `public` تلقائياً.

### التنصيب اليدوي (بديل)

```bash
mysql -u root -p -e "CREATE DATABASE school_archive CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"
mysql -u root -p school_archive < database/schema.sql
mysql -u root -p school_archive < database/seed.sql
cp app/config.sample.php app/config.php   # ثم عدّل بيانات الاتصال
```

بيانات الدخول الافتراضية عند التنصيب اليدوي: `admin` / `Admin@123`
— **غيّرها فوراً بعد أول دخول.**

## الأدوار والصلاحيات الافتراضية

| الدور | الصلاحيات |
|---|---|
| **مدير النظام** | كل الصلاحيات بلا استثناء |
| **مدير المدرسة** | الاطلاع على كل المعاملات، القيد والتعديل، الإحالة، التقارير، سجل الأحداث |
| **وكيل المدرسة** | مثل مدير المدرسة عدا سجل الأحداث |
| **مسؤول الأرشفة** | إدارة كاملة للمعاملات والوثائق وشجرة الأرشفة والمرفقات والجهات |
| **موظف** | المعاملات التي أدخلها أو أُحيلت إليه فقط، مع رفع المرفقات |
| **مطلع** | اطلاع فقط دون أي تعديل |

الصلاحيات قابلة للتعديل بالكامل من «الأدوار والصلاحيات»، ويمكن إنشاء أدوار جديدة.

## ملاحظات تشغيلية

**رفع الملفات الكبيرة** — لرفع ملفات تتجاوز حدود الخادم، عدّل في `php.ini`:

```ini
upload_max_filesize = 100M
post_max_size = 105M
max_execution_time = 300
memory_limit = 256M
```

أو استخدم **روابط قوقل درايف** للفيديو والملفات الكبيرة — الطريقة الموصى بها،
فهي لا تستهلك مساحة الخادم ولا تتأثر بحدود الرفع.

**النسخ الاحتياطي** — انسخ قاعدة البيانات ومجلد المرفقات معاً:

```bash
mysqldump -u USER -p school_archive > backup-$(date +%F).sql
tar -czf uploads-$(date +%F).tar.gz storage/uploads
```

**التواريخ الهجرية** تُحسب بالخوارزمية الحسابية المعتمدة، وقد تختلف بيوم واحد
عن تقويم أم القرى الرسمي في بعض الشهور. يمكن ضبط عرض التواريخ
(هجري / ميلادي / كليهما) من إعدادات النظام.
