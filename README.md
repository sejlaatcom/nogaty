# نظام الخطط الأسبوعية للمعلمين

نظام ويب متكامل بلغة **PHP + MySQL** لإدارة الخطط الأسبوعية لمواد التدريس في المدارس:
المعلم يُدخل خطته الأسبوعية ويرسلها للإدارة، والإدارة تعتمدها، وعند الاعتماد تظهر الخطة
في واجهة الموقع الرئيسية جاهزة للطباعة أو التصدير إلى Excel.

---

## المزايا

### واجهة الموقع (عامة — بدون تسجيل دخول)
- عرض الخطط **المعتمدة فقط** حسب الأسبوع والفصل.
- ورقة خطة لكل فصل بتصميم الخطة الرسمية (ترويسة المدرسة، أيام الأسبوع، التواريخ الهجرية).
- طباعة الورقة أو حفظها PDF بضغطة واحدة، وتصدير Excel أو CSV.

### لوحة المعلم
- عرض المواد والفصول المسندة له في الأسبوع المحدد مع حالة كل خطة.
- محرر الخطة: أيام الأسبوع (الأحد – الخميس) × البنود (موضوع الدرس، الهدف التعليمي، الواجبات والمهام الأدائية، ملاحظات اختيارية).
- حفظ كمسودة، **حفظ تلقائي** كل دقيقة، ونسخ خطة الأسبوع السابق بضغطة.
- إرسال الخطة للإدارة للاعتماد، ومتابعة ملاحظات الإرجاع.
- الخطة المعتمدة تُقفل تلقائياً عن التعديل حتى تفتحها الإدارة.

### لوحة إدارة المدرسة
- **لوحة المتابعة**: تعرف من أكمل ومن تأخّر بالأسماء — لكل فصل (٦ من ٩ مواد اكتملت) ولكل معلم مع نسبة الإنجاز.
- اعتماد الخطط: مراجعة فردية، اعتماد/إرجاع جماعي، أو اعتماد كل خطط الأسبوع دفعة واحدة.
- إدارة المعلمين: إضافة/تعديل/إيقاف، توليد كلمات مرور، تصدير القائمة.
- إدارة المواد والصفوف والفصول وإسناد المواد للمعلمين (فردي أو جماعي).
- التقويم الدراسي: أعوام، فصول دراسية، وتوليد الأسابيع تلقائياً بالتاريخين الميلادي والهجري (أم القرى)، مع فتح/إغلاق الإدخال لكل أسبوع.
- طباعة **ورقة لكل فصل** لكل الفصول بضغطة واحدة (ملف PDF واحد).
- الاستيراد والتصدير: المعلمون، الإسناد، والخطط (Excel/CSV) مع نماذج جاهزة.
- إعدادات المدرسة: الاسم، إدارة التعليم، الشعار، اسم المدير، نص رسالة الأسرة، وإظهار/إخفاء عناصر الورقة.
- سجل العمليات (من فعل ماذا ومتى).

## المتطلبات

| المتطلب | الحد الأدنى |
|---|---|
| PHP | 8.1 فأعلى |
| قاعدة البيانات | MySQL 5.7+ أو MariaDB 10.3+ |
| إضافات PHP | `pdo_mysql`، `mbstring` (إلزامية) — `zip` لتصدير Excel — `intl` لتقويم أم القرى (يوجد بديل حسابي إن لم تتوفر) |
| الخادم | Apache مع `mod_rewrite` أو Nginx أو أي خادم يدعم PHP |

## التثبيت

### 1) التثبيت عبر المتصفح (الأسهل)

1. ارفع ملفات المشروع إلى الاستضافة.
2. اجعل جذر الموقع (Document Root) هو المجلد `public/`.
   - إن لم تستطع تغيير جذر الموقع، ارفع المشروع كما هو؛ ملف `.htaccess` في الجذر يعيد التوجيه إلى `public/` تلقائياً.
3. أنشئ قاعدة بيانات MySQL ومستخدماً لها من لوحة الاستضافة (أو اترك المثبّت ينشئها إن كانت الصلاحيات تسمح).
4. افتح في المتصفح: `https://your-domain.com/install.php`
5. عبّئ بيانات قاعدة البيانات وبيانات المدرسة وحساب المدير، ويمكنك تفعيل «بيانات تجريبية» للتجربة.
6. **احذف الملف `public/install.php` بعد انتهاء التثبيت.**

> يقوم المثبّت بإنشاء الجداول، وملف `config/config.php`، والمواد والصفوف الافتراضية،
> والعام الدراسي الحالي بفصوله الثلاثة، و13 أسبوعاً للفصل الأول.

### 2) التثبيت اليدوي

```bash
# 1) استيراد بنية قاعدة البيانات
mysql -u USER -p DBNAME < database/schema.sql

# 2) إنشاء ملف الإعدادات
cp config/config.sample.php config/config.php
#   ثم عدّل بيانات الاتصال داخل الملف

# 3) إنشاء حساب مدير النظام
php tools/create_admin.php admin "كلمة-المرور" "مدير المدرسة"
```

### التشغيل محلياً للتجربة

```bash
php -S localhost:8080 -t public
# ثم افتح http://localhost:8080/install.php
```

## البدء بعد التثبيت

الترتيب الموصى به داخل لوحة الإدارة:

1. **إعدادات المدرسة** — الاسم، إدارة التعليم، الشعار، اسم المدير.
2. **الصفوف والفصول** — أضف الصفوف ثم الفصول (يمكن إضافة فصول لكل الصفوف دفعة واحدة).
3. **المواد** — عدّل قائمة المواد بما يناسب المرحلة.
4. **المعلمون** — أضفهم يدوياً أو استوردهم من ملف CSV.
5. **الإسناد** — أسند لكل مادة في كل فصل معلماً.
6. **التقويم والأسابيع** — فعّل العام والفصل الدراسي، ثم ولّد الأسابيع بتاريخ أول يوم أحد.
7. المعلمون يدخلون خططهم → **اعتماد الخطط** → تظهر في واجهة الموقع.

### بيانات الدخول التجريبية
عند تفعيل «بيانات تجريبية» أثناء التثبيت تُنشأ حسابات معلمين بكلمة مرور موحّدة `123456`
(أسماء المستخدمين: `saad`، `ahmed`، `majed`، `fahad`، `turki`، `bandar`، `walid`، `omar`، `nayef`).
**غيّرها أو أوقفها قبل الاستخدام الفعلي.**

## صيغ الاستيراد والتصدير

جميع الملفات بترميز **UTF-8**، ويمكن تنزيل نماذج جاهزة من صفحة «استيراد وتصدير».
عند الحفظ من Excel اختر: `CSV UTF-8 (Comma delimited)`.

### المعلمون
| الاسم | اسم المستخدم | كلمة المرور | الجوال | البريد الإلكتروني | رقم الهوية | المسمى الوظيفي |
|---|---|---|---|---|---|---|
| محمد بن أحمد | mohammed | 123456 | 05xxxxxxxx | mail@example.com | 10xxxxxxxx | معلم |

- الحساب الموجود مسبقاً (بنفس اسم المستخدم) **يُحدَّث** ولا يُكرَّر.
- إن تُركت كلمة المرور فارغة تُولَّد تلقائياً وتُعرض في نتيجة الاستيراد.

### الإسناد
| الاسم | اسم المستخدم | المادة | الصف | الفصل |
|---|---|---|---|---|
| محمد بن أحمد | mohammed | الرياضيات | الخامس الابتدائي | أ |

- يمكن تفعيل خيار إنشاء المواد والصفوف والفصول غير الموجودة تلقائياً.

### الخطط
| الأسبوع | الصف | الفصل | المادة | البند | الأحد | الاثنين | الثلاثاء | الأربعاء | الخميس |
|---|---|---|---|---|---|---|---|---|---|
| 1 | الخامس الابتدائي | أ | الرياضيات | موضوع الدرس | الكسور العشرية | جمع الكسور | طرح الكسور | تمارين | اختبار قصير |

- قيم عمود «البند»: `موضوع الدرس` / `الهدف التعليمي` / `الواجبات والمهام الأدائية` / `ملاحظات`.
- تصدير CSV لأي أسبوع يخرج بنفس هذه الصيغة، أي يمكن تصدير الخطط وتعديلها في Excel ثم إعادة استيرادها.
- خيار «اعتماد الخطط المستوردة مباشرة» يجعلها تظهر في الموقع فوراً.

## الطباعة و PDF

- زر **«طباعة / حفظ PDF»** يفتح الورقة بتنسيق طباعة (A4 أفقي) ثم اختر «حفظ كـ PDF» من نافذة الطباعة.
- ورقة كل فصل تُطبع في **صفحة مستقلة**، وزر «طباعة أوراق كل الفصول» في لوحة الإدارة يخرج ملفاً واحداً يحتوي ورقة لكل فصل.
- تصدير **Excel (.xlsx)** يخرج الورقة بنفس التنسيق (اتجاه من اليمين لليسار، دمج خلايا المواد، ألوان الترويسة) بدون الحاجة لأي مكتبة خارجية.

## إعداد Nginx (اختياري)

```nginx
server {
    server_name  plans.example.com;
    root         /var/www/weekly-plans/public;   # جذر الموقع = مجلد public
    index        index.php;

    location / {
        try_files $uri $uri/ =404;
    }

    location ~ \.php$ {
        include        fastcgi_params;
        fastcgi_pass   unix:/run/php/php8.2-fpm.sock;
        fastcgi_param  SCRIPT_FILENAME $document_root$fastcgi_script_name;
    }

    # منع تنفيذ أي ملف داخل مجلد المرفوعات
    location ~* ^/uploads/.*\.(php|phtml|phar)$ { deny all; }
}
```

مجلدا `app/` و`config/` خارج جذر الموقع في هذا الإعداد، فلا يمكن الوصول إليهما من المتصفح.

## الأمان

- كلمات المرور مُشفّرة بـ `password_hash` (bcrypt) مع إعادة التشفير التلقائي.
- جميع الاستعلامات عبر **Prepared Statements** (لا حقن SQL).
- حماية **CSRF** لكل النماذج، وتحقق من الصلاحيات في كل صفحة.
- إيقاف مؤقت بعد 8 محاولات دخول خاطئة خلال 15 دقيقة.
- ترميز كل المخرجات بـ `htmlspecialchars` (لا XSS).
- منع الوصول المباشر لمجلدات `app/` و`config/` ومنع تنفيذ أي سكربت داخل مجلد المرفوعات.
- المعلم لا يستطيع فتح أو تعديل خطة مادة غير مسندة له، والخطة المعتمدة مقفلة عن التعديل.

**بعد التثبيت:** احذف `public/install.php`، واستخدم HTTPS، وتأكد أن `config/config.php` غير قابل للقراءة من المتصفح.

## التخصيص

| ماذا تريد؟ | أين؟ |
|---|---|
| إظهار صف «ملاحظات / إثراء» في الخطة | إعدادات المدرسة → خيار إظهار الملاحظات |

| تغيير ألوان النظام | متغيّرات `:root` في `public/assets/css/app.css` |

## أسئلة شائعة

**تظهر رسالة «تعذر إنشاء ملف config/config.php»** — امنح مجلد `config` صلاحية الكتابة (755 أو 775) أثناء التثبيت فقط.

**ملف CSV يظهر بحروف مشوّهة في Excel** — استخدم ملفات التصدير من النظام مباشرة (تحتوي على BOM)، وعند الحفظ اختر `CSV UTF-8`.

**التواريخ الهجرية غير دقيقة** — فعّل إضافة `intl` في PHP للحصول على تقويم أم القرى الرسمي؛ وبدونها يُستخدم حساب جدولي تقريبي (قد يفرق يوماً)، ويمكن دائماً تعديل تاريخ أي أسبوع يدوياً.

**كيف أنقل النظام لعام دراسي جديد؟** — أضف العام الجديد وفعّله من «التقويم والأسابيع»، ثم ولّد أسابيعه وأعد الإسناد (بيانات الأعوام السابقة تبقى محفوظة).
